# مسابقة المدود (على نمط Kahoot)

مسابقة مباشرة متعددة اللاعبين بالعربية (RTL) عن المدود ومراتب المدود: 15 سؤالًا، مؤقّت وحساب نقاط على الخادم، ترتيب مباشر، ومنصة تتويج للمراكز الثلاثة.

## هيكل المشروع
```
server/index.js      الخادم: Express + Socket.IO (الغرف، المؤقّت، النقاط، الترتيب)
server/questions.js  الأسئلة ومفاتيح الإجابة (عدّلها هنا)
public/              الواجهة (index.html, style.css, app.js)
test/simulate.js     اختبار آلي بثلاثة مشاركين
data/results.json    تُحفظ فيه النتائج النهائية تلقائيًا
.env.example         المتغيرات (PORT, PUBLIC_URL)
```
اخترت واجهة JavaScript خفيفة بدل React/Vite لتقليل خطوات البناء وسهولة النشر على أي استضافة Node. يمكن نقلها إلى React لاحقًا لأن الخادم منفصل عنها تمامًا.

## التشغيل محليًا
```
npm install
npm start          # ثم افتح http://localhost:3000
npm test           # اختبار آلي (21 فحصًا)
```
للانضمام من هواتف على نفس الشبكة افتح على الحاسوب عنوان الشبكة المحلية، مثل `http://192.168.1.20:3000`، وليس `localhost`، فيظهر في رمز QR العنوان الصحيح. (أو ضع `PUBLIC_URL` في ملف `.env`.)

## النشر برابط عام
يحتاج خدمة تدعم Node و WebSocket، مثل Render أو Railway أو Fly.io (حساب مجاني يكفي للتجربة).
1. ارفع المجلد إلى مستودع GitHub.
2. أنشئ Web Service: أمر البناء `npm install` وأمر التشغيل `npm start`.
3. اضبط `PUBLIC_URL` على الرابط العام (اختياري، وإلا يُؤخذ من المتصفح).
ملاحظة: الغرف تُحفظ في ذاكرة الخادم، وإعادة تشغيله تُنهي المسابقات الجارية. ولا ينفع النشر على خادم بنسخ متعددة دون تخزين مشترك.

## رمز QR
يُولَّد تلقائيًا في شاشة المضيف ويفتح `الرابط/?pin=الرمز`. اعرض الشاشة على جهاز كبير ليصوّره المشاركون.

## دليل المضيف
1. افتح الموقع على الحاسوب واختر **إنشاء مسابقة** ثم مدة السؤال (10/15/20/30 ثانية).
2. اعرض الرمز وQR. يظهر المنضمّون في الردهة مباشرة. للتجربة بدون مشاركين اضغط **وضع التجربة** لإضافة 3 لاعبين وهميين.
3. اضغط **ابدأ المسابقة**. يُغلق السؤال تلقائيًا عند انتهاء الوقت أو إجابة الجميع، أو اضغط **إنهاء السؤال الآن**.
4. اضغط **كشف الإجابة**: تظهر الإجابة والشرح وعدد من اختار كل خيار والترتيب. ثم **السؤال التالي**.
5. بعد السؤال 15 تظهر منصة التتويج والترتيب الكامل، ومنها **جولة جديدة** أو **الصفحة الرئيسية**.

**النقاط:** للإجابة الصحيحة فقط: `round(1000 × (0.5 + 0.5 × الوقت المتبقي ÷ مدة السؤال))`، محسوبة من وقت استلام الخادم. الخاطئة وغير المجابة = 0.
**التعادل:** الأكثر نقاطًا، ثم الأكثر إجابات صحيحة، ثم الأقل مجموع زمن للإجابات الصحيحة.

## حدود معروفة
- لم أنشر الموقع على الإنترنت؛ اختبرته محليًا عبر محاكاة آلية فقط (لم أجرّبه على هواتف حقيقية).
- لا توجد قاعدة بيانات SQLite: الغرف في الذاكرة والنتائج النهائية في `data/results.json`.
- لا يُقبل انضمام جديد بعد بدء المسابقة (يمكن لمن انقطع الاتصال العودة تلقائيًا).

## خدمات خارجية
خط IBM Plex Sans Arabic من Google Fonts (يعمل الموقع بخط بديل بدونه). لا حسابات أخرى مطلوبة غير الاستضافة عند النشر.

## إذا لم يفتح الموقع من أجهزة أخرى
1. **العنوان:** لا تفتح `localhost` على الهاتف؛ استخدم العنوان الذي يطبعه الخادم عند التشغيل (مثل `http://192.168.1.20:3000`). والمضيف يستبدل `localhost` تلقائيًا في رمز QR.
2. **الشبكة:** يجب أن يكون الهاتف على نفس الواي فاي (لا بيانات الجوال). بعض شبكات الجامعات والفنادق تعزل الأجهزة عن بعضها؛ جرّب نقطة اتصال (Hotspot) من هاتفك.
3. **جدار الحماية:** في ويندوز اختر «السماح» عند ظهور نافذة Node.js، أو افتح المنفذ 3000.
4. **رابط عام فوري بدون نشر:** `npx cloudflared tunnel --url http://localhost:3000` (أو ngrok)، ثم ضع الرابط الناتج في `PUBLIC_URL` وأعد التشغيل.
